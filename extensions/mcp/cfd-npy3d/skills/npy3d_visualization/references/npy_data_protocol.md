# X/Y/Q .npy 数据协议（npy3d_* 依赖）

## 文件约定

- 同一目录下应有 X/Y/Q 三个 `.npy` 文件；
- 文件名只需分词包含 `x`/`y`/`q` 即可命中（如 `NACA_Cylinder_X.npy`、
  `NACA_Cylinder_Y.npy`、`NACA_Cylinder_Q.npy`；大小写不敏感）。

## 形状语义

| 数组 | 支持形状 | 语义 |
|---|---|---|
| X | `(H,W)` 或 `(T,H,W)` | 网格点空间 X 坐标 |
| Y | `(H,W)` 或 `(T,H,W)` | 网格点空间 Y 坐标（须与 X 形状一致） |
| Q | `(H,W)` / `(C,H,W)` / `(T,H,W)` / `(T,C,H,W)` | 物理量场 |

推断规则：

- `X/Y` 为 `(T,H,W)` 时坐标沿时间重复，仅取最后一帧几何；
- `Q` 为 `(C,H,W)`（X/Y 静态）→ 单帧多通道；`(T,H,W)`（X/Y 带时间）→ 单通道多帧；
- `(T,C,H,W)` → 多通道多帧（CFD_TEST 即此布局：T=2490, C=5, H×W=221×51）。

## 读取

- 一律 `mmap_mode='r'` 打开：大文件只把用到的帧/块载入内存。
- X/Y 仅在打开时复制所需切片（约几百 KB~几十 MB），Q 按帧切片使用。

## 限制

- 要求规则矩形网格（H×W），散点/非结构数据不支持；
- 通道物理含义不做自动猜测（交给 `npy3d_inspect` 的范围统计辅助判断）；
- 动画需要抽样帧无 NaN，否则明确报错。
